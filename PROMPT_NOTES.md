# APEX Prompt Changelog

## TailoringLab System Prompt

### v1.1 — 2026-03-16

**Changes:**

- Added automatic language detection (Italian/English based on job posting language)

- Added three-question cover letter framework (Why this company / Why me / Why this role) — woven naturally, never as explicit sections

- Added cover letter quality rules: strong opening, 250-350 words, confidence without arrogance, grounded in real CV data

**Rationale:**

- Italian language unlocks full Italian student market

- Three-question framework reflects how senior HR professionals evaluate cover letters

- Quality rules reduce generic AI output and increase personalization

### v1.0 — project launch

**Changes:**

- Initial system prompt: career advisor persona, CV tailoring, cover letter generation, Alex interview questions

- Strict rule: never invent information not present in the CV
